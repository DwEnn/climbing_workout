# 운동 세션 근거·구성 감사 보고서

감사·반영일: 2026-07-30
초기 감사 범위: 푸쉬 6개, 코어 8개, 파워 6개, 손가락 신전근 1개
최종 활성 범위: 푸쉬 6개, 코어 6개, 파워 5개, 손가락 신전근 1개

## 최종 결론

초기 21개 운동을 동일한 5축 루브릭으로 선별한 뒤, 교체가 유리해 보인
11개 슬롯을 별도의 승인 게이트로 다시 검증했다. 최종 결과는 다음과 같다.

- 검증된 교체 7개
- 현재 운동 수정 3개
- 슬롯 제거 1개
- 미해결 0개

이후 최종 HTML 20개 재채점에서 76점을 받은 글루트 브릿지는 사용자 결정에
따라 추가 제거했다. 이후 코어를 주 1회 단독 통합 세션으로 바꾸면서 사용자가
행잉 니/레그레이즈를 선택했고, 중복 행잉 운동인 윈드쉴드 와이퍼도 제거했다.
현재 활성 운동은 18개다.

교체 후보는 총점 80점 이상, 출처 확인, 하드 실패 없음, 보유 장비·시간 적합,
최종 세션 통합 적합을 모두 통과해야 했다. 점수가 높아도 하나의 하드 게이트가
실패하면 채택하지 않았다. 이 규칙으로 고저항 손가락 신전 프로토콜,
중복 링 롤아웃, 하이니 대체안은 제외됐다.

최종 구조 검사는 4개 가이드, 활성 운동 18개, 내부 레퍼런스 링크 115개를
검사해 오류 0개, 경고 0개로 통과했다. 승인 게이트와 실패 조건 단위 테스트
10개도 모두 통과했다.

## 운동 영상 최종 감사

활성 운동 18개 모두에 카드 동작과 일치하는 공개 YouTube 영상 1개를 연결했다.
영상은 운동 근거가 아니라 동작 시연 자료로만 취급한다.

- 기존 정확 영상 유지: 8개
- 기사 링크뿐이던 카드에 영상 추가: 3개
- 다른 동작·범용 진행·재생 불가 영상을 교체: 7개
- 공개 상태 확인: 18/18
- 정확한 동작 일치: 18/18

주요 정정은 다이아몬드 푸쉬업을 표준 플로어 푸쉬업으로, 페이스풀을
로우-투-90:90 외회전으로, 일반 손목 신전 운동을 손등-주먹 마디
익스텐서-업으로, 일반 할로우/사이드 플랭크를 밴드가 포함된 정확한 변형으로,
측면 바운드를 제자리 싱글레그 홉-앤-스틱으로 바꾼 것이다. 재생 불가였던
손가락 신전근 썸네일도 실제 고무밴드 스프레드 영상으로 교체했다.

`validation/video-audit.yaml`이 운동 키, HTML 파일, YouTube ID, 확인된 제목·채널,
공개 상태, 동작 일치와 교체 이력을 기록한다. 검증기는 카드당 YouTube 링크
1개, 감사표와 HTML의 영상 ID 일치, 썸네일 ID 일치, 영상 라벨 존재를 검사한다.

## 최종 HTML 재채점

교체 승인 점수를 그대로 복사하지 않고, 반영된 HTML의 운동 카드와 최종 세션표를
기준으로 20개를 다시 채점했다. 글루트 브릿지와 사용자가 선택하지 않은
윈드쉴드 와이퍼를 제거한 뒤 남은 활성 운동 18개의 요약은 다음과 같다.

- 전체 평균: 84.8점
- 80점 이상: 17개
- 80점 미만: 1개
- 하드 실패: 0개

남은 80점 미만 운동은 HTML 처방을 수정해야 하는 `revise` 판정이다.

| 운동 | 점수 | 현재 HTML 문제 | 필요한 수정 |
|---|---:|---|---|
| 고무밴드 손가락 스프레드 | 79 | 하루 4~6세트 분산표와 한 번만 선택 수행 지침이 충돌하고 최대 용량은 3~5분을 넘길 수 있음 | 분산표 제거 또는 한 번의 시간·홀드 상한을 재정의 |

`validation/final-audit.yaml`은 현재 네 HTML 파일의 SHA-256도 기록한다. 운동명,
점수 합계, 출처 키, 판정 또는 HTML이 바뀌면 검증기가 재감사 필요 상태를 오류로
보고한다.

## 승인되지 않은 주요 후보

- 고저항 등척성 손가락 신전은 연구 자체는 직접 근거지만, 70% MES를
  실시간으로 확인하는 힘 센서 보드가 필요해 장비 하드 게이트에서 실패했다.
- 링 롤아웃을 코어 EX02와 EX03에 동시에 넣는 안은 운동 자체는 유효하지만
  최종 세션 중복으로 통합 게이트에서 실패했다.
- 하이니 런과 밴드 하이니 드라이브는 최대 파워 품질을 유지하는 슬롯으로
  충분하지 않았고, 후자는 확인한 출처가 정확한 정지형 동작을 처방하지 않아
  직접 근거 게이트도 통과하지 못했다.
- 카라비너 밴드 손가락 신전은 선언된 보유 장비에 카라비너가 없어 채택하지 않았다.

## 최종 세션

### 푸쉬 — 30~40분, 주 2회

`푸쉬업 플러스 → KB 오버헤드 프레스 → 플로어 푸쉬업 →
밴드 편심 삼두 신전 → 스탠딩 로우-투-캑터스 → 손목 익스텐서-업`

기존 링 푸쉬업·링 딥스의 불안정 프레스 중복을 없앴다. 직접 근거가 있는
동작과 세션에 맞춰 조정한 용량은 카드에서 `✅`와 `🔶`로 분리했다.

### 코어 — 단독 30~40분, 주 1회

`데드버그 준비 2세트 → 턱 프론트 레버 → 링 롤아웃 →
행잉 니/레그레이즈 → 밴드 안티로테이션 할로우 →
밴드 사이드 플랭크`

A/B 분할을 없애고 여섯 운동을 한 번에 수행하는 코어 전용일로 통합했다.
행잉 동작은 사용자가 선택한 니/레그레이즈 하나만 남겼으며, 윈드쉴드 와이퍼는
그립·어깨 매달림 피로 중복을 피하기 위해 활성 세션에서 제거했다.

### 파워 — 25~35분, 주 1~2회

`낮은 싱글레그 홉-앤-스틱 → 파워 풀업 → 파워 푸쉬업 →
스쿼트 점프 또는 점프 런지`

박스가 없으므로 불안정한 가구를 대체물로 사용하지 않는다. 마운틴 클라이머는
최대 파워 세션에서는 제거하고 별도 컨디셔닝 옵션으로만 남겼다.

### 손가락 신전근 — 선택적 3~5분

고무밴드 손가락 스프레드를 10초 홀드 중심의 저부하 활성화로 사용한다.
일일 의무 세션이나 부상 예방 프로토콜로 표현하지 않는다.

## 확인된 출처 정정

- 플라이오메트릭 6개 글의 저자는 Eric Hörst가 아니라 Lucie Hanes다.
