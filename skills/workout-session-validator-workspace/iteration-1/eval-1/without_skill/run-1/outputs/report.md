# 운동 세션 검증 보고서 — 베이스라인

## 결론

현재 네 세션을 그대로 “조건에 맞게 잘 찾은 운동 세션”이라고 판정하기 어렵다.

- 구조 검사: **실패** — 오류 1건, 경고 22건
- 운동 수: 4개 세션, 21개 운동
- 내부 참조: 153개 확인
- 운동 판정: 유지 1개, 수정 9개, 교체 11개
- 직접근거 오표기·오귀속 등 근거 하드 실패: 14개 카드
- 가이드 원본은 수정하지 않았다.

구조 검사 결과와 근거·프로그램 검토 결과는 서로 다른 층위다. 구조 검사에서 운동 카드와 내부 링크를 찾았다는 사실은 해당 처방이나 출처 귀속이 옳다는 뜻이 아니다.

## 1. 구조 검사

`python3 scripts/validate_guides.py --no-fail` 결과는 다음과 같다.

| 항목 | 결과 |
|---|---:|
| 세션 | 4 |
| 운동 | 21 |
| 감사 데이터에 연결된 운동 | 21 |
| 확인한 내부 참조 링크 | 153 |
| 오류 | 1 |
| 경고 | 22 |
| 최종 상태 | fail |

오류 1건은 손가락 신전근 카드 내부에 필수 `sets_reps_rest` 필드가 없는 문제다. 페이지 상단 루틴 영역에 용량 정보가 있더라도 해당 운동 카드 자체의 필수 필드를 충족하지 못한다.

경고는 다음 세 범주다.

- 직접근거로 선언된 카드 20개에 요구되는 `✅` 근거 마커 누락
- `CLAUDE.md`의 코어 운동 목록이 현재 가이드와 불일치
- `CLAUDE.md`의 면책 문구 위치 설명이 현재의 `index_only` 정책과 불일치

파워 세션의 홉-앤-스틱 카드만 `✅`와 `🔶`를 표시한다. 나머지 카드의 배지 행은 티어만 보여 주며 직접 처방과 원리 적용을 구분하지 않는다.

## 4. 우선순위

1. 손가락 카드의 필수 용량 필드를 추가하기 전까지 구조 검사를 통과시키지 않는다.
2. 14개 하드 실패 카드의 직접근거 표시와 저자·자격 귀속부터 수정한다.
3. 코어는 24세트 일괄 구성을 A/B 또는 15–20분 모듈로 줄이고, front lever 같은 고품질 기술성 동작을 앞쪽으로 옮긴다.
4. 파워는 상체 폭발 1–2개, 하체 폭발 1개, 착지 제어 1개 정도로 회전시키고 박스 없는 박스 점프와 후반 mountain climber를 뺀다.
5. Push는 OHP를 유지하되 푸쉬업과 딥스를 같은 날 모두 강하게 수행하지 않는다.
6. `CLAUDE.md`의 운동 목록과 면책 위치 설명을 현재 스펙에 맞춘다.

## 최종 판정

**Fail — 수정 후 재검증 필요.** 운동 후보가 모두 무효라는 뜻은 아니다. OHP처럼 유지 가능한 항목도 있으나, 현재 문서 상태에서는 구조 누락 1건과 근거 표시·귀속 오류가 겹쳐 세션 전체를 검증 완료로 승인할 수 없다.
