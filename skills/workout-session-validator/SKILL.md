# Workout Session Validator

클라이밍 보조 운동 가이드가 좋은 운동을 나열하는 데 그치지 않고, 사용자의
조건과 주장 근거를 일관되게 만족하는지 확인한다.

## 입력

- 저장소의 `validation/spec.yaml`
- 검증할 운동 가이드 HTML
- 있으면 `validation/video-audit.yaml`
- 필요하면 이전 감사표 또는 변경 기준점

기준 명세가 없다면 먼저 사용자의 수준, 장비, 세션 목적, 시간과 근거 정책을
확인해 명세를 만든다. 기존 문서가 충돌하면 최신 의도적 변경을 우선하되
충돌 자체를 보고한다.

## 검증 순서

1. 저장소 루트에서 `python3 scripts/validate_guides.py --no-fail`을 실행해 구조,
   카드 필드, 레퍼런스 링크, 증거 표기, 운동 영상과 문서 드리프트를 확인한다.
   최소 fixture나 별도 명세는
   `python3 scripts/validate_guides.py --spec <경로> --skip-audit --no-fail`로
   실행한다. 검사를 실행할 수 없다면 도구 한계를 보고하되, DOM 본문을 정확히
   대조하지 않은 오류 코드나 누락 표기를 추정해서 만들지 않는다.
2. 각 활성 운동 카드에 공개 영상 링크가 정확히 하나 있는지 확인한다. 영상 제목,
   채널, 공개 상태와 카드의 핵심 변형을 대조하고, 동작이 애매하면 저화질 프레임을
   직접 확인한다. 기사 링크, 재생 불가 썸네일, 일반 진행 영상, 인접 동작은
   통과시키지 않는다. 영상은 동작 시연이며 근거 출처로 승격하지 않는다.
3. 각 운동 카드의 주장을 출처 존재, 저자, 대상, 운동, 목적, 용량으로 분해한다.
4. 웹·PDF 원문을 읽고 다음 중 하나로 분류한다.
   - `direct`: Tier 1-4 출처가 해당 운동을 해당 목적으로 클라이머에게 명시적으로 추천
   - `principle`: 타 집단 연구 또는 일반 원칙을 클라이밍에 적용
   - `mixed`: 직접 근거와 원칙 적용 주장이 한 카드에 공존
   - `unverified`: 책·페이월·삭제 등으로 원문 확인 불가
5. 매체가 아니라 근거 항목의 성격으로 Tier를 정한다. Lattice 자료도 데이터,
   코치 추천, 편집 기사인지에 따라 Tier 1.5, 2, 4가 달라질 수 있다.
6. 각 기능 슬롯에서 현재 운동과 대안 두 개를 동일 루브릭으로 블라인드 채점한다.
7. 안전, 출처 왜곡, 필수 장비 불가를 하드 실패로 먼저 판정한 뒤 점수를 계산한다.
8. 최고 대안이 5점 넘게 높아도 자동 교체하지 않는다. 대체 후보 자체가 80점
   이상, 원문 확인, 하드 실패 없음, 장비·시간 적합, 새 세션 통합 통과를 모두
   충족할 때만 `verified_replacement`로 승인한다.
9. 통과 후보가 없으면 `revise_current`, `remove_slot`, `unresolved` 중 하나로
   남기고 운동별 판정과 세션 전체의 중복·피로·순서·시간 문제를 별도로 보고한다.

## 점수와 판정

`references/rubric.md`를 읽고 그대로 적용한다.

- 하드 실패 없음 + 80점 이상: 유지
- 하드 실패 없음 + 70~79점: 설명 수정 또는 조건부 유지
- 70점 미만 또는 하드 실패: 교체/제거 후보

현재 채택 여부는 대안 채점이 끝날 때까지 평가에 사용하지 않는다.

## 출력

다음 세 결과를 함께 제공한다.

1. 구조·영상 검사 요약
2. 영상 감사표: 운동 키, 영상 ID, 확인된 제목·채널, 공개 상태, 동작 일치,
   유지·추가·교체 이력
3. 운동별 감사표: 세션, 슬롯, 운동, 근거 분류, Tier, 점수, 판정, 핵심 문제,
   출처 URL, 대안 두 개
4. 보고서: 전체 결론, 치명적 문제, 세션별 권고, 문서 드리프트, 검증 한계

출처를 확인하지 못한 주장은 추정하지 말고 `unverified`로 남긴다. 검증 결과만으로
운동 페이지를 직접 수정하지 않는다. 사용자가 명시적으로 수정을 요청했다면
HTML, 영상 감사표와 자동 검사를 함께 바꾸고 전체 회귀 검사를 다시 실행한다.
